BYTEWORLD / DOCUMENTATION MVP · V1.0

Investigation guide.

GETTING STARTED

Enter an EVM address, select a network, and choose Analyze Contract. BYTEWORLD retrieves deployed bytecode over a public RPC endpoint and checks Sourcify for verified metadata. No wallet connection, account, or signing is required.

SUPPORTED NETWORKS

Ethereum Mainnet, Base, Arbitrum One, and Optimism. Default public RPC endpoints are used unless overridden in server environment configuration.

ANALYSIS & EVIDENCE

Verified ABI functions are shown when retrievable. Without verified source, the MVP identifies a limited set of well-known function selectors from bytecode. Selectors are clues, not proof of execution behavior. Proxy detection checks the EIP-1967 implementation storage slot. Owner, mint, pause, and upgrade indicators are heuristic and do not establish caller permissions or exploitability. Transaction traces, full decompilation, and relationship graphs are not available in this MVP.

CONFIGURATION

Optional server variables: PORT, ETHEREUM_RPC_URL, BASE_RPC_URL, ARBITRUM_RPC_URL, and OPTIMISM_RPC_URL. RPC URLs stay server-side. Public RPC availability and rate limits are outside BYTEWORLD's control.

REPORTS

Copy address and summary, or export the current report as a JSON file. Reports are held in browser memory and are not saved to a server. The bundled sample is labeled static and should not be treated as current live chain evidence.
